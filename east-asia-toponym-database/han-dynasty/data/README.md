# 中国漢代県名のアイヌ語解釈

**坂東の雲／木上欠月**

漢代の県名はすべてアイヌ語解釈可能です。それは中原が蛮族扱いした四夷こそが先住民で、殷、周の方が侵略者であったことを示しています。殷、周は、ヒプシサーマル期以降に南下してきた北方遊牧民で、中国先住民のまん中に盤踞しました。四夷、中華思想はそこから生まれています。つまり、自らの存在を正当化するために、先住民を悪者に仕立て上げたということです。

これは決して中国に限ったことではなく、日本も含め、全世界で当たり前のように行われていたことです。勝者はいつでも自らに都合の良い物語を創作し、後世に残そうとするものです。歴史、宗教、文化とは元来そういうもので、いずれの場合も人の心に都合良く形が変えられていきます。

この漢代の県名の解釈の虎の巻となったものは、朝鮮半島の『三国史記』地理志です。ここに挙げられている四百数十の見出しの地名は、いずれも時代による名称の変遷も記されているので、挙げられている地名総数は実に千件を越えます。これはほぼ漢代の県名と同じボリュームです。対になるデータは、[『三国史記』地理志　全地名のアイヌ語解釈](../../samguk-sagi/data/README.md) です。

『三国史記』地理志の地名、漢代の県名は、いずれも治所周辺の地勢を表現しています。『三国史記』の地名変遷はアイヌ語地名によくある同一地勢の言い換え表現となっていて、治所周辺の地勢と地名解釈の相互検証が多視点から可能でした。そこで確立させた解釈ルールを漢代の県名に当てはめていったという訳です。

結果は、前述したとおり、すべての漢代の県名はアイヌ語解釈可能でした。しかし、『三国史記』地理志とは異なる特徴もあります。

1. 使われているアイヌ語の単語が限られ、単調な表現、使い回しの表現がほとんどです。
2. 漢字音韻とアイヌ語の発音はほぼ一致していますが、微妙なズレが散見されます。『三国史記』地理志では見られません。

こういう現象がなぜ起こるのか。漢代の県名を命名した役人をプロファイリングしてみます。

漢代の県名を命名したのは、長安周辺の役人で、それは四夷出身です。なぜなら、四夷の言語であるアイヌ語の音韻をこれだけ精密に拾うことは、アイヌ語ネイティブでなければ不可能だからです。

しかし、彼らは地名を収集するために、自ら地方に趣くことなどありませんでした。中国は広大です。使いっ走りとなった四夷の使用人が地方から集めてくる地名のリストを中央で地図を広げながら眺め、それに”良字二字”をあてはめていったのです。表現が単調なのは、少数の命名者のこたつ記事だったからです。

『三国史記』地理志の高句麗時代の地名には、呪文のように長いものが数多く見られますが、地方から集められた地名も、アイヌ語の音韻を精密に拾ったものであれば、同じように長い表現になっていたはずです。四夷の地名を二字に簡略化させながら、かつ意味の通るように作り替えるのですから、これはやはりアイヌ語ネイティブの仕事だと考えざるを得ません。

また、アイヌ語の「シ(si)」と「ヒ(hi)」の発音が、江戸弁のようにクロスする例が散見されます。例えば「シル(sir)＝山」が「ヒル(hir)＝山」のような発音に転訛する例が全国で見られます。これは、それだけの広範囲に共通の訛りがあったとするよりも、これも中原の役人の訛りだったと考える方が合理的です。

## 解釈の前提

漢代の県名の解釈の前提として、『三国史記』地理志でも採用したルールを適用します。

アイヌ語の子音の「ル(r)」は漢字音には存在しないため、もっぱら「ュ(yu)」の音の漢字が充てられたと考えています。ですから、「シル(sir)＝山」は「シュ(syu)」、「キル(kir)＝山脚」は「キュ(kyu)」という発音の漢字が充てられることになります。「レル(rer)＝山陰」の場合は「レュ(ryu)」、「ピル(pir)＝傷（のように切り刻まれたような地勢）」は「ピュ(pyu)」です。

「シル(sir)」や「キル(kir)」は実際に「シュ(syu)」や「キュ(kyu)」の発音に近かった可能性があります。北海道アイヌ語で「シル(sir)・アゥ(aw)＝山の・角、枝分かれ」は「シラウ(siraw)」、「キル(kir)・アゥ(aw)＝山脚の・角、枝分かれ」は「キラウ(kiraw)」と発音されますが、漢字音韻を見ると「シュアゥ(syuaw)」、「キュアゥ(kyuaw)」となっています。北海道アイヌ語の方が、後世、開音音節言語の日本語の影響を受けているのではないでしょうか。

同様に「tu＝峰」は、北海道アイヌ語では「トゥ(tou)」と表記されることが多いですが、この「t」も「ティゥ(tiw)」の発音に近くなります。漢字の音韻からは「テュ(tu)」から「デュ(dyu)」「ヂュ(zyu)」の変化が読み取れます。

「テュ(tu)＝峰」と「チゥ(ciw)＝水流、水脈」の解釈がクロスして、両方に同じ漢字が使用されることもあります。このように、あえて複数の解釈が可能な漢字を充て、ダブルミーニングを意図しているかのような地名が散見されます。また、「アク(ak)」は「弟（のように小さいもの）」と「矢を射る（ところ）」の意味がありますが、これもいずれの解釈も採用して「小さく鋭く尖った峰」の形容に使われることが多く見られます。

また、中国大陸では、前述のように「シ(si)」と「ヒ(hi)」がクロスします。

## 凡例

### 音韻

上古音の配列は、次のとおりです。

**高本漢系統／王力系統／董同龢系統／周法高系統／李方桂系統**

- 各項は「聲母」「半角スペース」「韻母」の順に置きます。
- 当該の説が存在しないものは `-` と記します。

参考：[漢字古今音資料庫](https://xiaoxue.iis.sinica.edu.tw/ccr/)

### アイヌ語

解釈はリエゾンとシラブルにより、一文字の漢字を複数のアイヌ語単語の連続として読みます。カタカナに付したローマ字は、知里真志保『地名アイヌ語小辞典』の表記に準じます。

| 約束 | 例 |
| --- | --- |
| し＝**si**、ち＝**ci**、つ＝**tu**、ふ＝**hu** | shi / chi / tsu / fu とはしません |
| 小さい仮名は語末子音 | キル＝**kir**、アム＝**am**、アク＝**ak** |
| テュ＝**tu** | tyu とはしません |
| 有声音と無声音を区別しません | 城＝テュ・エ・エン、またはデュ・エ・エン |

アイヌ語「ク」は「弓」ですが、中国大陸および朝鮮半島では「矢」の可能性があります。サハリンおよびシベリア・アムール流域のニヴフ（ギリヤーク）語でも「ク＝矢」です。

### データの欄

抽出データは、各県について次の欄に分解しています。

| 欄 | 内容 |
| --- | --- |
| 州名 | 漢代の刺史部（司隸を含む） |
| 郡名 | 本文の「■（　）」に記された郡・国・尹 |
| 見出し | 県名・道名など |
| 時代 | 前漢／後漢／漢～ など |
| 現行地 | 「場所：現在の…」に記された比定地 |
| 地勢 | 治所周辺の地形 |
| 音韻データ | 上古音 |
| アイヌ語解釈 | カタカナ・ローマ字・日本語義 |

ローマ字ルビは、本文では漢字音の上に、データファイルでは `キル(kir)` の形で残します。郡名・国名は本文の表記に従います（同一の郡でも「鉅鹿」「巨鹿」のように揺れがある場合は分けて置きます）。既出・参照のみの見出しは、音韻欄を空のまま残します。

## 🕊️ おわりに / Concluding Remarks

**【日本語】**
私は、現在それぞれの歴史や文化の中で平和に暮らしている人々の営みを、深く尊重します。

かつて言葉や大地の記憶を共有していた東アジアの庶民が、国境や政治的イデオロギーの壁を越えて、いつの日か温かく手を結び合える時が来ることを願っています。古代の地名に刻まれた自然への畏敬の念と生活の記憶を紐解く作業は、私たちが未来において再び深く相互理解するための「共通の記憶のアルバム」を作る挑戦です。

もしこの普遍的な連帯のビジョンと、膨大な地名解釈の学術的価値に共鳴し、個人の時間と費用を投じて進めるこの研究を支えてくださる方がいらっしゃいましたら、温かいご支援（パトロネージュ）をいただけますと幸いです。

By decoding the reverence for nature and the lived experiences embedded in ancient place names, this project seeks to create a "shared album of memories" that serves as a bridge for our collective future.
