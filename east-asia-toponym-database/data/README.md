# 『三国史記』地理志　全地名のアイヌ語解釈

**坂東の雲／木上欠月**

古代朝鮮半島の地名は、1145年に完成した金富軾『三国史記』「地理志」（巻34–37）に記されている。そこには、統一新羅・景徳王代に改称された漢風地名（757年～）、景徳王以前——主に高句麗時代——のもとの地名（～757年）、そして高麗時代、『三国史記』編纂当時の地名（1145年）という、三つの層が重なっている。

これら異なる三つの時代の地名は、いずれもアイヌ語として解釈しうる。しかも基本的に、治所周辺の同一地勢を指した**言い換え表現**である。特筆すべきは、すべての地名において、例外なく、当時の朝鮮半島の言語であったアイヌ語地名へ、漢字の音韻が極めて精密に充てられているという事実である。

地名は、正史のように為政者の手で化粧された記録ではない。それゆえに、その土地に生きた人々の生の声が、仮借の漢字音の奥に残っている。本プロジェクトは、『三国史記』地理志の全地名をアイヌ語で読み解き、はるか古代の炊爨の煙が見えてくるような地勢の声を、いまに取り出そうとする試みである。

## 仮説

### 一．東夷南蛮と朝鮮半島先住民の、言語的・生物学的グラデーション

中国漢代の県名を見るに、中原からみた四夷の言語は、おそらくアイヌ語であった。中原の圧迫を逃れた東夷・南蛮の人々が朝鮮半島へ移り、アイヌ語地名を漢字で写し取った。東夷南蛮と朝鮮半島、そして日本の先住民は、言語を共有する以上、厳密な民族境界をもって切り分けることはできない。これらの地域の人々は、生物学的にグラデーションを帯びた、血を分けた同系同族である。縄文人と弥生人のあいだにも、明確な一線は引けない。

中国文明の中心は中原であり、そのルーツとなる殷・周は、ヒプシサーマル期以降に南下した北方遊牧民に由来すると考える。先住民である四夷とは別民族である。中原にとってアイヌ語は蛮族の言語にすぎなかった。しかし東夷のその先、朝鮮半島はアイヌ語を用いる人々の本場であった。音韻を保存しようとする本気度が、そこではまったく異なる。『三国史記』は、当時のアイヌ語ネイティブ話者の手によって書かれた、稀有な書物である。

### 二．バイリンガル話者による精密な漢字音韻仮借と、時代を超えた共時的な言い換え

朝鮮半島と中国を往来した人々は、アイヌ語と中国語の天才的なバイリンガルであったと考えられる。ゆえにアイヌ語地名へ、限りなく精密に漢字音韻が割り当てられた。その精度は、高句麗の世から高麗の世まで、変わらない。

地名を漢字に写した人々は、記録として残すだけでなく、のちに自らアイヌ語ネイティブとして読み返す必要があったはずである。しかし時代が下れば、中国漢字の発音は変ずる。過去に仮借された地名も、やがてアイヌ語として読めなくなる。最新の発音に合わせて表記を改める必然が生じる。

アイヌ語は、同一の土地に対する言い換えが多彩である。高句麗・統一新羅・高麗の各時代の地名は、一見すれば改名の歴史に見えるが、実のところ時代差をほとんど持たないのかもしれない。すでに土地土地に生きていた人々のあいだで、言い換えはいくつも存在していた。そのうちの一つを、その時代の漢字音ですくい上げれば足りた——そう考えれば、すべての時代の地名が、軌を一にして同一地勢を指していることも、滑らかに理解できる。

景徳王代の漢風改称さえ、アイヌ語地名の仮借表記であり、以前の地名を縮約したにすぎないことが多い。もし解釈と地勢が一致しないとすれば、比定地の誤りか、音韻の拾い方・解釈の誤りのいずれかである。漢字音韻を丁寧に拾い、アイヌ語として読めば、古代人の地勢解説がおのずと現れる。

## 記載の層——［A］［B］［C］

『三国史記』の地名は、おおよそ次の形式で記される。

1. 「**［地名B］**は、もと**［地名A］**で、景徳王代に改名した。今の**［地名C］**である。」
2. 「**［地名B］**は、もと**［地名A］**で、景徳王代に改名した。今もこれに因っている。」
3. 「**［地名B］**は、もと**［地名A］**で、景徳王代に改名した。今は**［地名C］**に合併されている。」

| 記号 | 時代 | おおよその年代 | 音韻の主な根拠 |
| --- | --- | --- | --- |
| **［A］** | 景徳王以前（主に高句麗） | ～757年 | 上古音 |
| **［B］** | 景徳王代（統一新羅の漢風地名） | 757年～ | 随唐音 |
| **［C］** | 『三国史記』編纂時（高麗） | 1145年 | 随唐音 |

命名時期の不明瞭な［A］は上古音を、［B］［C］は随唐音を参考に解釈する。該当しない記載は、金富軾（井上秀雄訳注、平凡社）の本文に従う。

景徳王以前の地名は、紀元後、漢字音末尾の「ɡ」「ɣ」が脱落しつつある時期にあたることが多い。末尾の響きは弱化し、ときに失われる。たとえば「兮」「牙」の類は、脱落の過程で音韻末尾が「エン」あるいは「ウン」へと弱化した例がある。

解釈の順は、『三国史記』の掲載順にはよらない。日本と縁の深い朝鮮半島南東部から西方の海沿いに進み、さらに北上する。

## 凡例

### 音韻

上古音／随唐音の配列は、次のとおりである。

**高本漢系統／王力系統／董同龢系統／周法高系統／李方桂系統／陳新雄系統**（陳新雄は随唐音のみ）

- 各項は「聲母」「半角スペース」「韻母」の順に置く。
- 当該の説が存在しないものは `-` と記す。
- 同一地名に同じ音韻行が重なる場合は一つに整理する。ただし上古音と随唐音が両方ある漢字は、両方を残す。

参考：[漢字古今音資料庫](https://xiaoxue.iis.sinica.edu.tw/ccr/)

### アイヌ語

解釈はリエゾンとシラブルにより、一文字の漢字を複数のアイヌ語単語の連続として読む。カタカナに付したローマ字は、知里真志保『地名アイヌ語小辞典』の表記に準ずる。

| 約束 | 例 |
| --- | --- |
| し＝**si**、ち＝**ci**、つ＝**tu**、ふ＝**hu** | shi / chi / tsu / fu とはしない |
| 小さい仮名は語末子音 | キル＝**kir**、アム＝**am**、アク＝**ak** |
| テュ＝**tu** | tyu とはしない |
| 有声音と無声音を区別しない | 城＝テュ・エ・エン、またはデュ・エ・エン |

アイヌ語「ク」は「弓」であるが、朝鮮半島では「矢」の可能性がある。サハリンおよびシベリア・アムール流域のニヴフ（ギリヤーク）語でも「ク＝矢」である。

「テュ＝峰」と「チゥ＝水流、水脈」のように、一つの漢字に複数の解釈が交差することがある。ダブルミーニングを意図したかのような地名も少なくない。

### データの欄

抽出データは、各地名について次の欄に分解している。

| 欄 | 内容 |
| --- | --- |
| 州名 | 統一新羅の州 |
| 見出し | 本文の地名見出し |
| 現行地 | 「現／…」に記された比定地 |
| 統一新羅地名 | ［B］ |
| 景徳王以前地名 | ［A］ |
| 三国史記編纂時地名 | ［C］ |
| 音韻データ | 上古音・随唐音 |
| アイヌ語解釈 | カタカナ・ローマ字・日本語義 |

ローマ字ルビは、本文では漢字音の上に、データファイルでは `キル(kir)` の形で残す。
