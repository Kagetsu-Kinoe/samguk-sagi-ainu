| 篇名 | 海内北経 |
| 条 | 大蠭、朱蛾、蟜、闒非、拠比尸、環狗、祙、戎 |
| 山海経訳 | 「大蠭、その状は蠭（はち）の如く、朱蛾はその状、蛾のよう。蟜はその人となり虎の文あり。脛にふくらはぎあり。窮奇の東にあり。闒非は人面で獣身、青色。拠比尸はその人となり、頸が折れ、神をふりみだし、片手なし。環狗はその人となり、獣の首に人の身。袜というものは人身で黒い首、従（たて）の目。戎はその人となり人の首で三つの角」 |
| 音韻データ | 上古音：「襪」- -／m ǐwat ／- -／- -／- - |
| アイヌ語解釈 | アイヌ語：袜＝「ムィ・アッ(muy-at)」＝「頂が・たくさんある（ところ）」 |
